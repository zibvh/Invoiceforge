# InvoiceForge

Mobile-first, vanilla HTML/CSS/JS invoice maker.

## Included
- 5 invoice designs
- Live preview
- NGN/USD/GBP/EUR/KES/ZAR currencies
- Dynamic line items, discount and tax
- Local autosave/history
- Logo upload
- Print / Save as PDF
- Email sharing via `mailto:`
- Native share sheet for WhatsApp/Telegram/etc.
- Copy invoice summary as text
- Standalone HTML invoice download
- Lucide icons
- Responsive, no-login frontend

## Run
Open `index.html` in a browser or serve the folder with any static host.

For the best PDF experience, use the browser print dialog and choose Save as PDF.
